● Project Overview & Objective

University students frequently require cross-disciplinary collaboration for complex course assignments, yet lack dedicated platforms to find peers with complementary skill sets (e.g. computer science students teaming with graphic design or finance majors).

The Solution: Curio Campus introduced a verified peer marketplace where students showcase project portfolios, publish urgent help requests, match verified skill badges, and coordinate seamlessly via encrypted in-app messaging and video calls.

● Key Technical Capabilities

Smart Skill Matching: Tag-based query engine indexing student expertise and course specialties.
Emergency Request Hub: Broadcast urgent assignment help signals across campus networks.
Real-time Encrypted Chat: Cloud Firestore real-time listeners for instant sub-second text and media exchange.
Seamless Dark / Light Mode: Custom theme provider supporting dynamic contrast adjustments.
